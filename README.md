# FashionVerse 2026 — Event Registration Website

FashionVerse 2026 is a simple, responsive event registration website created for a fictional fashion and cosmetics event. I built it using **HTML, CSS, and JavaScript** as a way to practice creating forms, styling web pages, and adding interactive features.

## Pages

* **Login** — A simple login page with an option to register
* **Registration Form** — Includes personal details, contact information, interests, feedback, and an event schedule
* **Success Page** — Displays a confirmation message after registration

## Tech Stack

* **HTML5** — Page structure
* **CSS3** — Styling, layouts, gradients, and responsiveness
* **JavaScript** — Form validation, DOM manipulation, and user interactions
